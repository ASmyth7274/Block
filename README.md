# Blocklands

A block-building exploration game for the browser, made in the spirit of the
classic era of sandbox games: the programmer-art look, smooth lighting, the
calm piano, the gray menus — and the feeling of not knowing what is over the
next hill.

Everything is generated by code: every texture, model, sound effect and piece
of music. No original game assets are used. Blocklands is a fan tribute and is
not affiliated with Mojang or Microsoft.

## Playing

- **Windows / desktop:** open `index.html` (or the single-file
  `dist/Blocklands.html`) in Chrome, Edge or Firefox. No install or server is
  needed. Click into the game to capture the mouse.
- **Phone / tablet:** open the same file, or host the folder (for example with
  GitHub Pages) and visit it. Touch controls switch on automatically. Use
  *Fullscreen* on the title screen and play in landscape.

WebGL 2 is required (any browser from the last few years).

### Controls (keyboard & mouse)

| Action | Key |
| --- | --- |
| Move / jump / sneak / sprint | W A S D, Space, Shift, Ctrl (or double-tap W) |
| Break / attack | Left mouse (hold) |
| Use / place / eat | Right mouse |
| Pick block | Middle mouse |
| Hotbar | 1–9, mouse wheel |
| Inventory | E |
| Drop item (stack) | Q (Ctrl+Q) |
| Swap offhand | F |
| Explorer's Journal | J |
| Chat / commands | T, / |
| Hide HUD / screenshot / debug / third person | F1 / F2 / F3 / F5 |
| Fullscreen | F11 |

Creative mode: double-tap Space to fly. Worlds with cheats accept commands
such as `/gamemode`, `/time set night`, `/give`, `/tp`, `/summon`, `/locate`.

### Touch controls

D-pad to walk (the centre button toggles sneaking), the arrow button on the
right to jump (two buttons for up/down while flying), drag anywhere to look,
tap to use or place, hold to break or attack (or to eat / draw a bow when
holding food or a bow). Tap a hotbar slot to select it, hold it to drop the
item, and use the `…` button for the inventory. Menus work by tapping; in
inventories, a short tap picks up a stack and a long press picks up half.

## Saving, export and import

Worlds save automatically in the browser (IndexedDB) every 30 seconds and when
you pause or quit. Use **Export** in the world list (or *Export World* in the
pause menu) to download a `.blocklands` file — only blocks you changed are
stored, the rest is regenerated from the seed, so files stay tiny. **Import**
on any device to continue the same world.

## What's in it

**The classic core:** survival with health, hunger and XP; mining with tool
tiers; 2×2 and 3×3 crafting with shaped and shapeless recipes; furnaces and
smelting; chests; beds that set your spawn; farming, bone meal and breeding;
buckets, flint and steel and TNT; flowing water and lava; fire; day/night,
rain, snow and thunderstorms; creative mode with the tabbed creative
inventory; hardcore mode.

**The classic look:** 16×16 textures, smooth lighting with ambient occlusion,
the classic lightmap, biome-tinted grass and leaves, fancy 3D clouds, sunrise
glow, stars and moon phases, view bobbing, the gray button GUI, the pixel font,
hotbar, hearts and hunger shanks, item tooltips, the title screen with its
splash text and a slowly turning live panorama.

**New to explore:**

- 23 biomes, including Autumn Woods, Redwood Groves, Moorland with stone
  circles, the Ashen Wastes with lava pools, blinding Salt Flats, banded Red
  Canyons and Wildflower Meadows.
- New ores and materials: ember (glows when struck), jade (high places),
  cobalt (deep in slate), sulfur (near lava), glowing lumite crystals in
  caves, and starmetal from craters left by falling stars — the strongest
  tools and armour of all.
- New creatures: Boomcaps (explosive toadstools), Mummies in the desert,
  Wraiths that drift over snow and moor at night, deer, bats, wisps, and the
  Stranger, who is only ever seen at a distance.
- Wisps that lead the curious to buried treasure (or release one yourself
  with wisp essence), runestones that wake when touched with jade, the
  Prospector's Rod that twitches towards ore, the Wayfinder that points at
  uncharted lands, and the Explorer's Journal that records every biome,
  creature and milestone you discover.
- Structures: ruined towers, camps, hermit huts, desert wells, sunken ruins,
  dungeons with monster cages, quicksand pits and buried chests.
- Generative music: calm piano pieces composed on the fly, different by day,
  by night and underground.

## Project layout

```
index.html            entry point (loads the scripts in order)
src/core              utilities, noise, block and item definitions
src/world             world generation (runs in web workers), chunks,
                      lighting, block behaviours, tile entities
src/render            WebGL renderer, chunk mesher, texture & model
                      generation, particles, entity rendering
src/entity            physics, player, items/projectiles, creatures & AI
src/game              settings, input, interaction, inventory, recipes
src/ui                pixel font, GUI widgets, menus, HUD, inventories,
                      chat & commands, journal, touch controls
src/audio             synthesised sound effects and generative music
src/storage           IndexedDB saves and world export/import
tools/build.js        builds dist/Blocklands.html (single file)
tools/test            headless-browser test harness and scenarios
```

Rebuild the single-file version with `node tools/build.js`.
