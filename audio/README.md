# Audio

Drop your own audio here and the game will pick it up.

- `music/` — soundtrack. Name each file after the track it is (e.g. the OST title);
  the game assigns tracks to places: title screen, overworld (day / night),
  caves, the deep dark, the Underworld, the Far Isles, creative mode.
- `sfx/` — sound effects. Name each file after what it is
  (e.g. `stone_break.ogg`, `door_open.mp3`, `zombie_hurt.wav`).

Formats: `.ogg`, `.mp3` or `.wav` (`.mp3` plays everywhere, including iPhone).
Anything not supplied falls back to the game's own built-in sounds and music.
